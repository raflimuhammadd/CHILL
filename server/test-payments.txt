Pre-requisites:
1. Backend running: npm run dev di folder server/
2. Database ready: 
- Migration 03_add_subscription_expiry.sql sudah dijalankan (ALTER TABLE users ADD subscription_expires_at)
- Seed data subscription_plans sudah ada 3 rows (individual, duo, family)
3. Midtrans credentials di .env:
MIDTRANS_IS_PRODUCTION=false
MIDTRANS_SERVER_KEY=SB-Mid-server-xxxxxx
MIDTRANS_CLIENT_KEY=SB-Mid-client-xxxxxx
4. JWT token: Login dulu via POST /api/auth/login → simpan accessToken
Test Flow (urutan):
1. Login → dapat token
2. Create Payment (BCA VA) → dapat order_code + va_number
3. Simulate payment di Midtrans Dashboard
4. Verify Payment → cek status jadi succeeded
5. Check user premium → GET /users/me
1. Login (dapat JWT token)
Endpoint: POST http://localhost:3000/api/auth/login
Headers:
Content-Type: application/json
Body (raw JSON):
{
  "username": "testuser",
  "password": "password123"
}
Expected Response:
{
  "success": true,
  "message": "User logged in successfully",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "username": "testuser",
      "email": "test@chill.com",
      "is_premium": 0
    }
  }
}
Action: Copy accessToken → pakai di semua request berikutnya.

Environment variables:
- base_url: http://localhost:3000
- token: (auto-set dari login response via test script)
- order_code: (auto-set dari create payment response)
Postman test script (auto-save token):
Di request Login, tab Tests, tambahkan:
pm.test("Login success", function () {
    pm.response.to.have.status(200);
    const res = pm.response.json();
    pm.environment.set("token", res.data.accessToken);
});
